# Result structure

Use actual decisions and source URLs; replace these field descriptions rather than returning placeholders.

1. **Site and concept:** 3–5 sentences in the user's language. Offer, audience, CTA, selected page placement and why this scene serves it. Separate verified facts from illustrative direction. Add a compact source ledger with access limitations.
2. **START:** the generated image and saved path, or a complete English image prompt in its own copyable block. If generated, include the prompt too for reproducibility.
3. **END:** the generated image and saved path, or a complete English prompt in its own block. State which actual START image was attached. If prompt-only, give the explicit attach-START instruction inside the prompt.
4. **VIDEO PROMPT:** one complete English block. Include scene, START/END roles, timing, motion, camera, invariants, and negatives. Add a separate complete one-image alternative only when the selected tool cannot accept two endpoints.
5. **Use settings:** placement, duration, master aspect, crop-safe region, HTML copy location, audio, poster, motion/accessibility fallback, once/scroll behavior. State the actual asset status and whether any video has been generated or tested.

Do not pad the response with multiple competing concepts or a questionnaire. Exactly two endpoint assets; do not count contact sheets, discarded attempts or an optional poster as extra endpoints.
